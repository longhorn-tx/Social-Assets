# Social Assets

A Next.js app for making social media assets (feed posts, Stories, Reels/TikToks,
YouTube thumbnails, LinkedIn visuals, carousel covers) with Higgsfield image and
video models. It's built on the
[Higgsfield Studio template](https://github.com/higgsfield-ai/app-templates)
and ships with the template's full model catalog: 38 picker entries from 28
model files in `generation/catalog/models/`.

## Run it

```sh
cd studio
pnpm install
cp .env.example .env.local   # HF_API_BASE_URL=https://api.higgsfield.ai
pnpm dev                     # http://localhost:3000
```

Click **Connect API key** in the sidebar and paste the API key copied from
[open.higgsfield.ai](https://open.higgsfield.ai/api-keys) as-is. A server action
stores the key in an HTTP-only cookie. Every authenticated Higgsfield request
(submit, status, cancel, signed upload URL) runs on the server with
`Authorization: Key <api-key>`. The browser never receives the key.

## Weekly content decks

Home opens on **This Week**: every post from the current content calendar,
grouped by brand (Longhorn, American Eagle Builders, American Concrete Coatings,
American Insulation, HomeStop), with an estimated cost.

1. **Open shot list** creates a project for the post and lists its shots.
2. **Draft still** (or **Draft N stills** for the whole post) makes a still per
   shot: Soul 2 for drafts, Flux 2 when a shot reuses an approved still as a
   reference, Ideogram 4.0 for text-heavy graphics.
3. Hover a still and click **Use this still** to approve it.
4. **Animate** turns the approved still into a 9:16 clip: Kling 3.0 Pro, or
   Seedance 2.0 for hero shots. Transformation shots animate from the previous
   shot's still to this one.
5. Shots marked **build in editor** (end cards, wipes) and all on-screen text,
   phone numbers and logos are added in CapCut/Canva.

Send each week's calendar and it gets added as a new deck
(see `content/README.md`). Cost labels are list-price estimates from public
pricing snippets; check open.higgsfield.ai/pricing for your rate.

The **Brand** pill in the dock adds that brand's look to free-form prompts, and
the Generate button shows an estimated cost for models with a known rate.

## Generate a whole week without the app

`pnpm assets` runs a deck end to end with ffmpeg installed and `HF_API_KEY`
(the full key from open.higgsfield.ai) in `.env.local` or the environment:

```sh
pnpm assets --deck 2026-10-19 --dry-run              # plan + list-price estimate, no spend
pnpm assets --deck 2026-10-19 --stage stills         # cents: one still per shot
pnpm assets --deck 2026-10-19 --redo hook,catch      # regenerate weak stills
pnpm assets --deck 2026-10-19 --stage clips --max-usd 20
```

Output goes to `out/<deck>/<post>/`: numbered stills and clips, the assembled
1080×1920 reel (`<post>.mp4`, clips trimmed to the deck's timings, on-screen
text burned in the safe zone, end cards with the contact line) and `notes.txt`
with the text, voiceover and end card for each shot. Statics produce the raw
images; headline/checklist layouts still go in Canva.

Cost rules built in: clips are only made from a still that exists (check the
stills before `--stage clips`), clip length is the shot's own length, Kling
sound is off, `--budget` uses Kling instead of Seedance, the run stops before
crossing `--max-usd`, and a queued request id is saved immediately so a rerun
resumes it instead of paying again. `HF_MOCK=1` makes placeholder media to
test the pipeline for free.

## Using it

- **Explore presets** pick a model and the right aspect ratio for each format,
  then fill in a prompt for you to edit.
- **Image / Video** switches surface. The model pill lists every installed model.
  The sliders button opens all of the selected model's settings.
- **+** uploads references. The server gets a signed URL, the browser PUTs the
  file directly to Higgsfield storage, and the public URL is used only after the
  upload succeeds.
- **Generate** turns into **Cancel** while a run is in flight. Cancel calls the
  platform's cancel endpoint; it doesn't just stop polling.
- History and projects are kept in this browser (IndexedDB/localStorage).

## Notes

- `generation/catalog/models.generated.ts` is regenerated by
  `scripts/sync-models.mjs` on every dev/build. Don't edit it by hand.
- Add or refresh models with
  `pnpm dlx shadcn@latest add higgsfield-ai/app-templates/<model>`. List them with
  `pnpm dlx shadcn@latest list higgsfield-ai/app-templates`.
- The key is per user (a cookie in each browser). If you switch to a shared
  server key (`HF_API_KEY`), first add authentication and store each
  `request_id` with its owner. Status and cancel must then check ownership.
